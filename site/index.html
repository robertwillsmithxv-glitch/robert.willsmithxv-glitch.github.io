Server features

Plugins & commands

Essentials

Commands

  • /rtpTeleport randomly in the world you are currently in.
  • /warp spawnTeleport to the server spawn.
  • /tpa <player>Request to teleport to another player.
  • /tpahere <player>Ask another player to come to you.
  • /tpacceptAccept a teleport request.
  • /tpdenyDecline a teleport request.
  • /sethome <name>Set a named home. You can set up to three homes.
  • /home <name>Teleport to one of your saved homes.
  • /chestsortConfigure chest sorting.
Server features

Vein miner

Crouch while mining an ore or chopping a tree and it breaks instantly.

Get connected

How to join Da SMP

1

Client

You can launch Eaglercraft 26.2 online:

Launch Eaglercraft 26.2

Or download the client to your computer:

Download ZIP
2

Add the server

  1. Open Eaglercraft and go to Multiplayer, then click Add Server.
  2. Name the server "Da SMP".
  3. Paste wss://server.brumby-tone.ts.net/play into the server address box.
Client compatibility

Clients older than 1.16 can connect, but blocks below Y=0 will not render because negative coordinates are a newer world feature.

3

Register and log in

Use a password command to protect your account and saved inventory.

First time joining?

/register "password" "confirmPassword"

You will be logged in automatically after registering.

Returning player?

/login "password"

Join with Java Edition

  1. Open Minecraft Java Edition and select Multiplayer.
  2. Choose Add Server. Enter Da SMP as the server name and wap-chit.tun.ply.gg as the server address, then save.
  3. Select Da SMP and click Join Server.

First time joining?

/register "password" "confirmPassword"

You will be logged in automatically after registering.

Returning player?

/login "password"

Join with Bedrock Edition

  1. Open Minecraft Bedrock Edition, choose Play, then open the Servers tab.
  2. Choose Add Server. Enter Da SMP as the server name, wap-brotherhood.tun.ply.gg as the server address, and 19132 as the port.
  3. Save the server, select it, and join.

First time joining?

/register "password" "confirmPassword"

You will be logged in automatically after registering.

Returning player?

/login "password"

No massive explosions

02
